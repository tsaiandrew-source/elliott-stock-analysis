# ELLIOTT+ STOCK ANALYSIS

Public front-end prototype for the stock-analysis chart surface.

- Home: `data-model/home.html`
- Daily/Weekly/GEX charts: `chart-surface/index.html`
- Representative tickers: NBIS and IREN
- Data: prototype contract based on the Google Sheets / GOOGLEFINANCE model
- Charting: TradingView Lightweight Charts attribution is retained in the UI

This deployment contains only the prototype front-end files. The operating
repository and private analysis archives are not included.
